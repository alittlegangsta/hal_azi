# Research question
Directional reception performance of a multi-station azimuthal acoustic receiver sonde.

# Data and sample
Laboratory measurements of a 64-sensor, eight-station sonde.

# Instrument or method
Three-sensor phased subarrays are formed from circumferential sensors and compared with individual elements.

# Main findings
The reported subarrays narrow the dominant reception lobe and support incident-direction estimation.

# Limitations
Directional response does not supply a common absolute reference between independent tools.

# Relevance to this thesis
Supports the distinction between receiver index, directional sensitivity, and absolute tool azimuth.
