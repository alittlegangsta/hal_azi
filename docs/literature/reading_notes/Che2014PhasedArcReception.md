# Research question
Whether phased-arc subarrays improve directional reception relative to independent elements.

# Data and sample
Controlled transducer directivity experiments.

# Instrument or method
Adjacent circumferential piezoelectric elements are delayed and summed as phased subarrays.

# Main findings
The subarray's main lobe is narrower and its incident-direction amplitude contrast is greater.

# Limitations
The experiment concerns receiver directivity, not cross-tool registration.

# Relevance to this thesis
Supports the distinction between channel geometry and a global azimuth reference.
